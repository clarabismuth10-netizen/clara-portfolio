# Clara — Portfolio website

Responsive editorial portfolio starter for a Lead Brand / Art Director. Static HTML/CSS/JS; no build tools or paid dependencies.

## Preview
Open `index.html` in your browser.

## Personalise before publishing
- Replace `CLARA®` if desired and update the profile text.
- Replace `YOUR.EMAIL@example.com` with your professional email.
- Cover images are typographic placeholders, not actual campaign imagery. Replace them with your own approved assets.
- On each page in `projects/`, replace the video placeholder with an embed, for example:
  `<iframe src="https://player.vimeo.com/video/VIDEO_ID" title="Campaign film" allow="autoplay; fullscreen; picture-in-picture" allowfullscreen></iframe>`
  Put the iframe inside `.video-wrap`. The CSS already sizes iframes to fill the 16:9 frame.
- Replace the two gallery placeholders with images using `<img src="../assets/your-image.jpg" alt="Description">`.
- Confirm you have permission to publish all client/brand images and films.

## Publish for free with GitHub Pages
1. Create/sign in to GitHub and create a public repository, e.g. `clara-portfolio`.
2. Upload the contents of this folder (not the ZIP itself): `index.html`, `assets/`, `projects/`, and this README.
3. Open **Settings → Pages**.
4. Choose **Deploy from a branch**, select `main` and `/ (root)`, then Save.
5. GitHub will show a live URL similar to `https://YOUR-USERNAME.github.io/clara-portfolio/`.

Alternative: Netlify also offers free hosting for static sites: https://app.netlify.com/drop

A custom domain is optional and usually costs extra. External fonts need an internet connection.
